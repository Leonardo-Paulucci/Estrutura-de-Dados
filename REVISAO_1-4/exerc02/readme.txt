Exercício 2 - Sistema de Rede / TI
Você foi contratado para desenvolver um sistema simplificado de suporte técnico.

Estrutura do Projeto:
SistemaTi/
main.c
fila.c
fila.h 
pilha.c
pilha.h 
lista.h 
lista.c 

Comando para compilar no terminal:
gcc main.c fila.c pilha.c lista.c -o sistema.exe

Comando para executar:
./sistema.exe
